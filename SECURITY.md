# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue: on GitHub, open the
repository's **Security** tab and choose **Report a vulnerability**. Include the Vandal version
(Settings › About), your Windows version and the steps to reproduce.

You'll get a reply within a week. Fixes ship in the next release, and the release notes credit
you unless you'd rather not be named.

## Supported versions

Only the latest release gets security fixes. Install new versions over the old one from the
[Releases](https://github.com/flowcat-software/vandal/releases) page.

## Checking a download

Each installer comes with a build provenance attestation and a SHA-256 checksum. The README's
[Verify your download](README.md#verify-your-download) section explains how to check them.
